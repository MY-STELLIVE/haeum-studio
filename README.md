# HAEUM STUDIO v1.0.0

뭐해음님 전용 개인용 크리에이터 대시보드의 초기 실행 버전입니다.

## 실행 방법
1. ZIP 압축을 풉니다.
2. `index.html`을 브라우저에서 엽니다.
3. GitHub Pages에 배포하려면 저장소 루트에 폴더 안의 파일과 폴더를 업로드합니다.

## 포함 기능
- 다크 Liquid Glass 스타일 UI
- 반응형 PC 사이드바 / 모바일 메뉴
- 화면별 메뉴 전환
- 한국 표준시(KST) 시계
- 초기 프로필 및 방송 통계 표시
- JSON 데이터 백업 및 가져오기
- 초기 데이터 파일 `data/initial-data.json`

## 현재 미구현 / 주의
- 치지직 실시간 방송 상태 및 시청자 자동 연동
- 자동 방송 일정 수집
- 개별 방송별 상세 데이터
- 이미지 자료실 실제 이미지
- 검색, 데이터 편집 UI
